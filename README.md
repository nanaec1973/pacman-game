# 🎮 Telegram Mini Apps Collection

Репозиторий статических веб-приложений (HTML5 / Canvas / JS), работающих как Telegram Mini Apps через GitHub Pages.

## 🕹️ Доступные игры:

1. **☕🐾 Кошачье Кафе: Снек-Бар (`cafe.html`)**
   - Уютный тайкун ресторана котиков (по мотивам *Cat Snack Bar*).
   - Кот-шеф Барсик готовит заказы, пушистые гости посещают кафе, прокачка скорости и выручки, столики и су-шеф.
   - Ссылка: `https://nanaec1973.github.io/pacman-game/cafe.html`
   - Локальное сохранение в `localStorage`.

2. **🐱 Кото-Тапалка (`cat.html`)**
   - Графический кликер 60 FPS с гардеробом, битвами с боссами и мини-играми.

3. **🐍 Неоновая Змейка (`snake.html`)**
   - Классическая аркадная змейка со спецэффектами.

4. **🕹️ Пакман (`index.html`)**
   - Ретро-аркада Pac-Man.

---

## 💾 Хранение данных
Игры используют локальное сохранение в браузере пользователя (`localStorage`). Серверная база данных на данном этапе не используется.
